# Craft Link Repair

## Restore the links in a local export

This sample is an unpacked Craft export with three pages. Each TextBundle has an info.json file with a page identifier.

1. Open **Craft Link Repair: Preview repaired copies**.
2. Select **Craft Link Repair/Export**.
3. Select **Preview links**, then **Write copies**.

The preview shows page links, date links, and two unresolved links. Source notes stay intact.
