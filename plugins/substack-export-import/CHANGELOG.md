# substack-export-import

## 1.1.1

### Patch Changes

- Save profile, Load profile and Compare bodies now show how to get Pro, with a Sponsor on GitHub button.
- The Sponsor on GitHub button adds the plugin id to the GitHub address, so a sponsorship shows its source.
- If GitHub has said you sponsor, or your first check still runs, no Sponsor button shows.

## 1.1.0

### Minor Changes

- After a minor or major update, Substack Export Import opens one What's new tab in the background. The tab and settings card suggest other NoteMods plugins and Zovo Chat and link to notemods.com for feedback ([privacy](https://notemods.com/privacy/)). The tab sends no data. Turn the tab off in Settings. Add the Send feedback command. The plugin makes no new network requests.
