# Protected text

Normal prose gets bold word starts. Important terms that are **already bold** keep their original emphasis.

## Code stays exact

Inline code such as `const value = 1` stays unchanged. So does this block:

```js
const value = 1;
const label = "Reading is fast";
```

## Math and scripts

The equation $x + y = z$ stays unchanged.

日本語のテキスト。한국어. العربية.

Greek and Cyrillic words use the same letter count: κόσμος Привет.

Use the word starts as a visual guide. The effect does not rewrite this note.
