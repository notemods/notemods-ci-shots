# A plain reading session

This note has the fixation property set to false. Its prose stays plain while the effect is enabled for other notes.

## One note can stay quiet

Use this property for a poem, a draft, or a page where the added emphasis does not help. The property belongs to the note. It takes priority over the folder and tag rules.

The note keeps its heading, links, and paragraph spacing. You can read and edit the original source with the plugin enabled or disabled.

> The choice applies to this note. Other open notes can keep their bold word starts.
