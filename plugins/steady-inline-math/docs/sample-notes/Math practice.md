# Math practice

Use one caret in a plain paragraph. Put it just inside a dollar sign, type a space, then move it into the text.

The first result is $x+y$. Keep the equation active while you add a space before x.

The second result is $E=mc^2$. Add a space after the last term, then leave the equation.
