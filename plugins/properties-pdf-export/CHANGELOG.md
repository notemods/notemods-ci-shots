# Changelog

## 1.2.2

### Patch Changes

- f810f50: Without Pro, Folder layouts now shows no rules, because no rule is in effect. Your saved rules stay.

## 1.2.1

### Patch Changes

- f71e165: An edit of Folder layouts without Pro now shows how to get Pro, with a Sponsor on GitHub button. Before, the text saved but had no effect. Nothing is saved until Pro is on.

## 1.2.0

### Minor Changes

- After a minor or major update, Properties in PDF Export opens one What's new tab in the background. The tab and settings card suggest other NoteMods plugins and Zovo Chat and link to notemods.com for feedback ([privacy](https://notemods.com/privacy/)). The tab sends no data. Turn the tab off in Settings. Add the Send feedback command. The plugin makes no new network requests.

## 1.1.0

### Minor Changes

## 1.0.0
