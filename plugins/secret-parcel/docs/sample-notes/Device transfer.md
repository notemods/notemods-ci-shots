# Device transfer

Move two sample secret IDs from the work laptop to the travel tablet.

## Before export

- Check the source vault.
- Select openai-key and github-token.
- Leave todoist-token on the source device.
- Use a long, unique passphrase.

## On the target device

1. Copy the encrypted parcel into the target vault.
2. Open Import parcel and enter the passphrase.
3. Check the new IDs and conflicts.
4. Keep conflicts unticked unless replacement is intended.
5. Read the written, skipped and failed report.
6. Delete the parcel when it is no longer needed.

Sample values are used for these screenshots. No live account keys are used.
