# Sentence study

Use Subtitle Sentence Miner to turn local dialogue into a card note.

## Source files

- French.srt has six short sentences with cue numbers and times.
- Travel.vtt has two travel questions with VTT timing settings.

## Study steps

Select a source, set one answer, review the Markdown and create a new note.

The subtitle text stays in its source file. Card notes keep the source path and both times.
