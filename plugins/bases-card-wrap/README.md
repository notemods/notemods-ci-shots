Wraps long property values in Bases card views onto more lines, or clamps them to a set number of lines, for each base and view.

## Install

When Bases Card Wrap is listed in the community directory, open Settings, then Community plugins, then Browse, and search for "Bases Card Wrap". Select Install, then Enable.

To install by hand, download `main.js`, `manifest.json` and `styles.css` from the latest release. Put the three files in `<vault>/.obsidian/plugins/bases-card-wrap/`. Restart Obsidian or reload the list of community plugins, then turn on Bases Card Wrap.

## Settings

After a minor or major update, this plugin opens one What's new tab in the background. The tab and settings card suggest other NoteMods plugins and Zovo Chat and link to notemods.com for feedback ([privacy](https://notemods.com/privacy/)). The tab sends no data. Turn the tab off in Settings.
