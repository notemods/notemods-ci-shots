# shared-tex-preamble

## 1.1.1

### Patch Changes

- The Shared TeX Preamble notice for a Pro feature now has a Sponsor on GitHub button.

## 1.1.0

### Minor Changes

- After a minor or major update, Shared TeX Preamble opens one What's new tab in the background. The tab and settings card suggest other NoteMods plugins and Zovo Chat and link to notemods.com for feedback ([privacy](https://notemods.com/privacy/)). The tab sends no data. Turn the tab off in Settings. Add the Send feedback command. The plugin makes no new network requests.
