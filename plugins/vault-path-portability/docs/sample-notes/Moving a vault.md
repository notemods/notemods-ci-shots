# Moving a vault

Scan the indexed paths before you copy this vault to a new device.

- Open the report with **Scan vault paths**.
- Review Windows reserved names and unsafe characters.
- Copy the complete report as Markdown.
- Keep a backup before changing paths.

The scan never changes files. Pro rename actions need an explicit click.
